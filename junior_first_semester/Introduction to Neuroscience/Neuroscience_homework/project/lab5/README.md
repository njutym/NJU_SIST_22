## 使用说明：
#### 1.psychopy的安装
在终端运行pip install psychopy即可，psychopy官网：https://www.psychopy.org/download.html。
最好用python3.8或者python3.10，需要安装pandas之类的基础包。

#### 2.进行实验
在一次实验中，需要被试将工作目录切换到lab5文件夹下，运行lab5_judge_size.py文件，进行简单的分类任务（预计一次实验用时30s以内）：

首先输入被试昵称（必须全是英文字母或者数字）和试验编号，格式必须为“xxx_01”(01表示第一次实验，以此类推)。然后按下任意键后，屏幕左侧和右侧会分别出现不同大小的椭圆，屏幕中心会固定出现一个“×”号。被实需要盯着屏幕中间的“x”号不动，利用余光判断左边和右边的椭圆哪一个大，若左边大则按下左键（f）(请务必使用左手按)，反之按下右键（j）（请务必使用右手按）。被试需要在优先保证正确率的同时，尽可能迅速地完成任务 , <span style="color:red">注意，该实验对时间要求比较高。耗时如果比较长(大于0.6s)的话会收到屏幕中央“Faster”的提示，可以模拟一下自己会受到“惩罚”。</span>在该实验中还有一个非常重要的记忆模块，从一开始到结束实验，每隔几个椭圆就需要被试记住一个数字（0-9）（被试需要记住的是数字的顺序），在实验结束后被试会被提问几个形式如下的问题：第几个数字是？被试需要在文本框中输入答案，且拥有1次输错的机会，如果超出这个机会本次实验将作废。

**实验至少需要进行5次。**

#### 3.统计结果
运行一次lab5_judge_size_plot.py文件，然后输入自己的昵称即可，会在./results文件夹里看到实验结果。能够看到自己实验的准确率和反应时，绘制出选右概率以及反应时间随着比例r（r=右圆大小÷左圆大小-1）的变化图，前一张图理论上应该是单调递增，后一张图理论上应该是近似中心为0的正态分布。实验结果如果不符合预期可以不管。
