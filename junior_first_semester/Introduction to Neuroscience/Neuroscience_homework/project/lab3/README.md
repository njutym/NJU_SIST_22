## 使用说明：
#### 1.psychopy的安装
在终端运行pip install psychopy即可，psychopy官网：https://www.psychopy.org/download.html。
最好用python3.8或者python3.10，需要安装pandas之类的基础包。

#### 2.进行实验
在一次实验中，需要被试将工作目录切换到lab3文件夹下，**分别**运行lab3_judge_size_left.py文件和lab3_judge_size_right.py**至少各六次**，进行简单的分类任务（预计每次实验用时30s以内）：

首先输入被试昵称（必须全是英文字母或者数字）和试验编号，格式必须为“xxx_01”(01表示第一次实验，以此类推)。然后按下任意键后，屏幕左侧和右侧会分别出现不同大小的椭圆，屏幕中心会固定出现一个“×”号。被实需要盯着屏幕中间的“x”号不动，利用余光判断左边和右边的椭圆哪一个大，若左边大则按下**f键(请务必使用左手按)**，反之按下**j键（请务必使用右手按）**。被试需要在优先保证正确率的同时，尽可能迅速地完成任务 , <span style="color:red">注意，该实验中，会提前告诉被试左边或者右边圆更大的概率，被试可以利用好这一个先验概率。</span>该实验对反应时间也有一定要求。耗时如果过于长(大于0.6s)的话会收到屏幕中央“Faster”的提示，需要略微提速。这个0.6的参数可以调整，如果将lab3_judge_size_left.py和将lab3_judge_size_right.py里75行的阈值从0.6修改即可，如果经常看到faster可以调大，反之调小。


#### 3.统计结果
分别运行一次lab3_judge_size_plot_left.py和lab3_judge_size_plot_right.py文件，然后输入自己的昵称即可，会在./results_left以及./results_right文件夹里看到实验结果。能够看到自己实验的准确率和反应时，绘制出选右概率以及反应时间随着比例r（r=右圆大小÷左圆大小-1）的变化图，前一张图理论上应该是单调递增但是会有偏向，后一张图理论上应该是基本对称的接近正态分布，但中间应该会有凹陷，整张图也可能会有偏向。实验结果如果不符合预期可以不管。
